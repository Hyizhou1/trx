# TRX 自动兑换能量机器人

当你自己设置的收款地址收到用户转账后，机器人会自动为用户返还能量。

## 功能说明

- 自动监听指定地址的转账记录
- 用户付款后自动返还能量
- 已对接第三方平台，可直接购买即用
- 适合做自动化 TRX 能量兑换服务

## 第三方平台价格

| 时间段 | 65K 能量 | 131K 能量 |
|---|---:|---:|
| 10:00 - 19:00 | 1.71 TRX | 3.446 TRX |
| 19:00 - 20:30 | 1.91 TRX | 3.849 TRX |
| 20:30 - 22:00 | 2.11 TRX | 4.252 TRX |

## 适用场景

适用于需要自动化处理用户充值，并即时返还能量的 TRX 业务场景。
